# 本 fork 发布约定

- 上游分叉基线是 Breeze v3.0.35，提交 `b994df92fb5f270afd768d97854d4286c657d749`。只保留最新 Release 时，说明应以上游当前最新正式版为功能对照（本次为 v3.0.36），同时如实注明原始分叉基线；不能仅列与上一轮本地版本的差异，也不能将功能对照写成已合并上游全部提交。保留上游归属与侧载说明。
- Breeze 的 Release 只放应用产物及相应校验文件。插件集中在 `kl5212840-lang/Breeze-plugins` 发布，通过 `main/plugins_data.json` 上架；`updates/*.json` 分别提供真实版本和匹配附件的更新索引，不能把应用附件当作插件商店。
- 插件先准备独立、可下载的 Release，再更新商店目录。核对 UUID、版本、图标、更新地址、下载附件和实际 `getInfo()`；保留升级身份与配置键。仅发布地址变化也应递增插件补丁版本，使已本地安装的用户能从商店更新。
- 核对远端目录合并结果、插件下载及元数据后，再移除错误分发的附件。删除旧 Release 前保存本地元数据；删除 Release 不等于删除源码、Git 标签或提交。
- 本分支默认只保留最新的 Breeze Release。插件各自的 Release 不随应用的旧版本一起删除；不更改上游仓库。
- 不用未构建源码冒充已有安装包。文案和商店目录修正不需要重建 IPA；应用行为变化必须单独验证并构建对应版本。

- 本轮最终发布统一命名为 v3.0.37（build 2262）。原 v3.0.36–v3.0.42 编号视为内部测试迭代；冲突旧标签在本地及远端归档后，最终版标签指向已验证的发布提交。
