# 图源一体化入口：首版任务书

## 目标

把「发现」从一串彼此割裂的插件功能入口，改为可一键进入图源的入口。首个验收图源是拷贝漫画。进入后，推荐、上架、发现、排行、云端收藏在同一图源界面中切换；原有书架、搜索、阅读和插件设置不被取代。

## 本次交付与验收

- 已启用且提供漫画列表功能的图源卡片有明确的「启动」操作；点一次进入图源，默认打开首个可用栏目。
- 图源界面持续显示图源名称及栏目导航；切换栏目无需返回「发现」，返回时保留该界面之前访问过的栏目状态。
- 栏目来自插件公开的 `functions` 动作，不在宿主硬编码漫画列表接口；搜索只搜索当前图源，筛选、漫画详情和阅读继续沿用现有实现。
- 图源的账号入口进入现有插件登录流程。只有插件明确提供安全的 HTTPS 注册页时才显示注册入口，注册在系统浏览器完成；不自行猜测第三方注册 API，不在宿主 WebView 收集注册凭据。
- 失效、禁用或不提供列表功能的插件维持原行为；现有功能快捷入口仍可用。
- 补充模型/交互测试，静态检查、插件构建及 iOS 模拟器构建通过，并进行模拟器目视验证。

## 不在本次范围

- 不重写第三方网站的注册接口、验证码和邀请逻辑。
- 不改变第三方图源的服务器、内容规则或账号资料。
- 不承诺所有图源都能像原生独立 App 一样提供相同栏目；界面依据插件实际公开的能力显示。
- 不在未经验证的情况下覆盖现有 SideStore 安装或用户数据。

## 交付判定

代码和测试完成后，记录实际通过的验证项与不能在模拟器证明的真机/在线站点行为。未经验证的行为不标为完成。

## 当前实现与验证（2026-10-19）

- 「发现」中的可浏览图源增加“启动”；对应旧栏目快捷按钮从发现卡片收起，其他独立工具入口保留。栏目按插件 `openComicList` 声明生成。图源内用持续可见的底部导航切换栏目，已访问栏目保留状态。
- 图源内有当前图源搜索、账号及插件设置入口。插件登录成功后重载当前栏目；拷贝漫画插件提供外部 HTTPS 注册页入口，打开前显示域名确认。
- 插件 fork 当前版本为 `0.0.15`。在 fork 发布 Release 前禁用自动更新通道，避免向不存在的地址检查更新或意外安装上游版本。
- 已通过 `dart analyze lib test/source_shell test/login`、插件 `pnpm typecheck`/`pnpm build`、完整 `flutter test`（124 项）、iOS Simulator Debug 与 iOS Device Release（未签名）构建。
- 本地交付物位于 `build/ios/ipa/`：`Breeze-custom-unsigned.ipa` 与 `breeze-plugin-copy-comic-0.0.15.bundle.cjs.br`。IPA 仍需由 SideStore 等工具签名；插件包需另行导入，二者不能互相替代。
- 尚未在真机上安装和测试新 IPA，也未核实第三方站点当前注册流程或登录成功后的云端收藏。不要在备份前覆盖手机上现有的同 Bundle ID 应用。

## iOS 27.0 模拟器联网验证（2026-10-19）

- 已在 iPhone 17 Pro Max / iOS 27.0 模拟器构建并运行集成测试。未安装到真机。
- 本机系统代理当前监听 `127.0.0.1:7897`，但调试资源 `.env.proxy` 保存的是已失效的 `127.0.0.1:8000`；调试版自动探测失败后没有启用该代理。该资源只用于本地调试，不应把本机回环地址写入真机配置。
- 同一图源的 `getHomeRecommend` 请求在模拟器不指定代理时以 `Request timed out: GET` 失败；测试启动时指定 `--dart-define=SIM_PROXY_URL=http://127.0.0.1:7897` 后返回 18 条。推荐与全新上架两个页面均在 Flutter 组件树中渲染出 18 条条目。
- 集成测试可用 `--dart-define=SIM_ASSERT_PLUGIN_CONTENT=true` 验证页面内容；`SIM_PROBE_PLUGIN_NETWORK=true` 则单独打印图源请求条目数。代理地址由测试参数传入，不写入生产配置。
- 当前模拟器系统截图接口在后续运行中捕获到启动图，虽组件树测试通过，仍不能把这些截图当作已加载内容的视觉验收。先前未指定代理的截图停在加载中。真机网络、登录及阅读仍需单独验证。

## 搜索页适配补丁（2026-10-19）

- 在 iPhone 17 Pro Max / iOS 27.0 模拟器打开图源搜索时，发现展开的输入框靠近屏幕右缘会被压缩并出现横向溢出。现改为保持目标宽度、必要时将浮层向左移动。
- 增加 1320×2868、3 倍像素密度的右缘回归测试；搜索组件与图源入口共 11 项相关测试通过，改动文件静态分析无错误。模拟器 Debug 构建已包含补丁。
- 本文上方 `Breeze-custom-unsigned.ipa` 在此补丁前生成，尚未重新打包；不能把它当作包含最新搜索适配修复的安装包。真机安装仍未进行。

## 前台模拟器人工验收与待办（2026-10-19）

- Device Hub 保持在前台的 iPhone 17 Pro Max / iOS 27.0 模拟器。用户从插件商店列表安装了图源；不再重复通过本地 URL 安装。
- 真实画面已确认“启动”进入常驻图源页面；漫画推荐、全新上架、发现、排行榜均加载出了封面与条目，在同一底部导航切换，无需退出图源。云端收藏未登录时会要求登录，未测试登录后的内容。
- 初次启动因模拟器未走代理而超时。宿主调试构建现在可通过 `--dart-define=SIM_PROXY_URL=http://127.0.0.1:7897` 指定本机代理；仅调试模式读取，不写入真机配置。代理启用后上述四个公开栏目均加载成功。
- 用户从插件商店安装的是云端版本；登录页未出现 fork 新增的“注册账号”入口。该入口仍需在模拟器安装本地 fork 插件包后目视验收，不能把云端版本的行为视为 fork 验收结果。
- 本地 fork 包已复制到模拟器中 Breeze 的 Documents 目录，供用户通过“插件商店 → 本地安装”选择；无需输入本地 HTTP URL。复制后 SHA-256 与构建产物一致。
- 用户发现空白搜索会向插件提交空字符串并报 `keyword 不能为空`。宿主已在提交入口拦截空白/纯空格输入并给出本地化提示；代码已热重载，等待用户手动复验。搜索有关键词时用户已确认可返回结果。
- 拷贝漫画 fork 中“云端收藏”未登录错误曾被宽泛的登录错误捕获逻辑误判为“登录已失效”。现将读取凭据移到网络请求错误捕获之外：无凭据提示“请先登录后再使用收藏功能”，有凭据却被接口拒绝才提示登录失效。已重新构建并放入模拟器 Breeze Documents；需从“本地安装”重新导入该插件后才会生效。
- 漫画列表条目经 `ComicInfoRoute` 进入详情；章节入口经 `ComicReadRoute` 进入阅读。二者使用路由压栈，返回会回到仍在栈中的图源界面；这一点完成代码审查，实际阅读返回及栏目状态仍待模拟器人工验收。
- 真机安装、账号注册/登录、漫画详情与阅读仍未完成验证。
