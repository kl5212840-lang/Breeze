# 3.0.38 插件版本兼容迁移

本轮仅基于已发布内容。iOS 基线为 `v3.0.37`（0242d5f7，build 2262）；Android 基线为补发的 2263 安装包（实际 versionCode 4263），按当时 839 项构建输入摘要恢复，包括已发布的 22 项平台补充文件。两端分别构建，不以正在开发的 3.0.39 工作区为输入。

## 更新协议

- 插件 UUID 与数据库模型不变。插件公开版本重启为 0.1.0；`releaseSeries: 1` 是更新协议字段，不是展示版本。
- 当前目录为 `Breeze-plugins/main/catalog/v1/plugins_data.json`，每个插件更新入口为 `updates/v1/<key>.json`。根目录旧目录与旧索引继续保留。
- 从旧系列迁移时，同时核对 UUID、已发布版本和 `originScript.trim()` 的 UTF-8 SHA-256（`migrationFrom`）。未知本地内容不跨系列自动替换。
- 同系列继续按版本递增。目录合并优先系列，防止旧缓存将正式系列降回旧数字较大的版本。
- 正式系列安装包在运行 getInfo 前校验 `scriptSha256`，随后核对 UUID、版本与系列。失败保留旧包。
- 下载期间删除、替换脚本或切换调试状态的操作优先。自动更新保留启用状态、顺序和原记录主键；不改动插件配置、收藏、阅读记录。
- 这 5 个 0.1.0 包由已发布 CJS 只改版本和更新入口生成，撤销元数据后与原包逐字节一致。未来业务修改必须递增公开版本。

## 验证

`test/plugin/plugin_release_policy_test.dart` 覆盖版本、系列、内容摘要与身份约束。
`test/plugin/published_migration_integration_test.dart` 通过离线 HTTP/QJS 边界替身运行实际目录、安装、更新、数据库与商店按钮流程；不读取用户账号或本机生产数据库。
`test/plugin/cloud_catalog_fallback_test.dart` 与 `plugin_catalog_merge_test.dart` 覆盖旧缓存、目录合并与离线回退。

原始发布安装包摘要、Android 基线恢复记录、构建输入和测试日志留在本机验收目录。插件源码与发布包由 Breeze-plugins 独立发布，客户端 Release 只包含 IPA/APK 与摘要文件。

Android 构建额外将客户端检查更新固定到本分支发布入口，避免误装其他分支；已发布原生超分组件按安装包摘要原样保留，见 `3.0.38-android-source.json`。

重建本次 Android 兼容版前，从保留的 v3.0.37 Release 下载 b2263 arm64 APK，并运行 `python3 script/release/restore_published_android_native.py --apk <APK路径>`；校验摘要后恢复原生组件。正式构建继续使用仓库外的独立签名配置。
