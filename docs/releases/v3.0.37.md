# Breeze v3.0.37 · iOS / iPadOS

相对[上游 v3.0.36](https://github.com/deretame/Breeze/releases/tag/v3.0.36)，本版集中带来：

- 新增原生影视片库、分类检索、作品详情与多线路播放。
- 完善横竖屏、手动选集、续播、收藏分类与同步。
- 优化漫画筛选、详细列表、长目录及阅读恢复。
- 统一返回、菜单和设置体验，改善云端组件加载。

提供未签名 IPA，需自行签名侧载，更新前建议备份。由本 fork 独立维护，感谢上游 [deretame/Breeze](https://github.com/deretame/Breeze)。
