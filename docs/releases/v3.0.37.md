## 功能更新

- 新增影视浏览、播放、收藏和下载功能。
- 优化图源分类、搜索与漫画阅读体验。
- 统一插件分发和更新入口，支持已安装插件迁移，保留配置与记录。

## 修复与优化

- 增加插件更新校验，避免覆盖本地修改的插件。
- 优化 Android 网页交互、系统返回、分享与下载保存。

## 下载与安装

- Android：[ARM64 安装包](https://github.com/kl5212840-lang/Breeze/releases/download/v3.0.37/Breeze-Android-v3.0.37-arm64-v8a.apk)，支持 Android 8.0 及以上。

本次为同版本补发，旧包用户请手动下载安装；Android 沿用原签名，可覆盖安装。不同签名版本请先备份数据。插件在应用内插件商店单独更新。
