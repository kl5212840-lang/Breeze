# Breeze v3.0.37 · iOS / iPadOS

以当前上游 [Breeze v3.0.36](https://github.com/deretame/Breeze/releases/tag/v3.0.36) 为功能对照，本 fork 的主要扩展与改进：

- 新增 iKun 原生片库、分类检索、多线路播放、文件夹收藏、续播与更新检查，支持 Breeze 收藏同步。
- 完善漫画详细列表、题材筛选、搜索范围、长目录及阅读恢复，配套更新哔咔、禁漫和拷贝插件。
- 优化 Hanime1 原生与网页浏览、账号入口、横竖屏播放器、手动选集及返回体验。
- 恢复插件商店的云端组件，优先展示五个维护插件；增加目录缓存和离线兜底，统一插件更新入口与使用声明。

本版本由 [kl5212840-lang/Breeze](https://github.com/kl5212840-lang/Breeze) 独立维护，原始分叉基线为上游 v3.0.35；以上是相对当前上游版本的功能概述，并非宣称已完整合并其后续提交。感谢上游 [deretame/Breeze](https://github.com/deretame/Breeze)。

本页仅提供 **iOS / iPadOS 未签名 IPA（build 2262）**及校验文件，需自行签名侧载，更新前建议备份。插件请在应用内「插件商店」安装或更新，统一目录管理、在 Breeze-plugins 统一发布；第三方内容、线路及账号权限以原站为准。其他平台请使用上游渠道。
