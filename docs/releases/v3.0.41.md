# Breeze v3.0.41 · iOS / iPadOS

- 新增 Hanime1 原生浏览、视频播放和常用账号操作。
- 完善搜索筛选、订阅与“我的”页，统一插件入口和设置。
- 改进播放器横竖屏、手动选集及返回恢复，修复菜单关闭和刷新时序问题。

**配套插件：Hanime1 0.11.2。** 安装新版 IPA 后，在插件管理中从本地安装随附的 `Hanime1-native-v0.11.2.cjs`；已有插件可直接更新。

本次提供本 fork 的 iOS / iPadOS 未签名 IPA，需自行签名侧载，安装前建议备份数据。上游项目：[deretame/Breeze](https://github.com/deretame/Breeze)。
