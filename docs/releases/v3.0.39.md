# Breeze v3.0.39 · iOS / iPadOS

这是 [kl5212840-lang/Breeze](https://github.com/kl5212840-lang/Breeze) 独立 fork 的未签名 IPA，不是上游官方构建，也不是 App Store 安装包。

## 本次改进

- 禁漫天堂+、哔咔漫画+等图源共用的首页导航现在会先返回个人页内部记录、上一个栏目，再退出插件。
- 只有真正离开图源时，左上角才显示有色且带文字的“退出”按钮；普通返回仍用箭头。
- “我的”记录列表不再出现两个返回箭头；文件夹管理的系统返回不会一次跳过两层。

## 安装

下载 `Breeze-iOS-v3.0.39.ipa`，使用自己的签名工具侧载。与上一版本保持相同的应用标识和签名团队时，通常可以覆盖安装并保留本地数据；若签名方式或应用标识改变，可能无法覆盖。安装前建议备份应用数据。

图源插件可继续在应用内的插件商城独立更新；本次修改位于 Breeze 应用端，不需要重新安装插件。
