# Breeze v3.0.36 · iOS 发布说明

本版本由 [kl5212840-lang/Breeze](https://github.com/kl5212840-lang/Breeze) 独立构建，基于 [deretame/Breeze](https://github.com/deretame/Breeze)。不是上游官方版本。

## 下载与安装

- 下载 `Breeze-iOS-v3.0.36.ipa`。这是未签名的 iOS / iPadOS 安装包，须使用自己的签名工具侧载，不能直接安装或通过 App Store 更新。
- 更新前建议先在旧版应用中备份数据。其他平台请使用上游发布渠道，本次没有 Android、Windows、macOS 或 Linux 安装包。
- 「哔咔漫画+」为独立插件，安装应用后在插件商城单独安装或更新；不会覆盖原有的哔咔插件。[插件发布页](https://github.com/kl5212840-lang/Breeze-plugin-bika-personal/releases)。

## 本次调整

- 优化首页导航和发现页布局，发现页支持列表与网格浏览。
- 统一哔咔搜索、收藏与历史的详细列表体验，保留封面网格切换。
- 优化哔咔分类预览、排行榜、漫画详情与阅读操作布局。
- 改进网络错误和登录失败时的提示；插件调用报错不再附带表单参数。

## 使用提醒

- 哔咔漫画+ 的最新版插件需与本分支客户端配合使用；如仍显示旧界面，先确认应用和插件都已更新。
- 云端插件配置仍按原有范围同步，其中可能包含插件登录凭据。请使用可信的私有 WebDAV / S3 空间，并优先使用 HTTPS。现有同步加密不应被视作只有你能解密的端到端加密。
- 真机安装及交互体验仍需使用者自行验收。
