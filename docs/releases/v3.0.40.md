# Breeze v3.0.40 · iOS / iPadOS

这是 [kl5212840-lang/Breeze](https://github.com/kl5212840-lang/Breeze) 独立 fork 的未签名 IPA，不是上游官方构建，也不是 App Store 安装包。

## 本次改进

- 哔咔漫画+、禁漫天堂+ 的分类屏蔽会实际过滤结果，相同的排序不再同时占用两个筛选入口；拷贝漫画保留自身支持的高级筛选。清空搜索历史需要确认。
- 搜索结果显示当前页和可信的总页数，可按页跳转；哔咔漫画+ 的详细列表补充作品页数。
- 漫画详情的标签、简介、目录与相关推荐更紧凑：标签按内容宽度排列，简介移到目录之前，长目录在限定区域内滚动，推荐卡片留出间距。
- 发现页插件管理入口更清晰；关于应用指向本 fork，同时保留上游项目归属与贡献者。
- 更新日志按顺序展示本 fork 的版本，再接上原仓库至 v3.0.35 的历史记录。

禁漫天堂+ 插件 0.3.2 单独修正搜索总页数，请在应用内插件商城更新。哔咔漫画+ 和拷贝漫画本次没有独立插件更新。

## 安装

下载 `Breeze-iOS-v3.0.40.ipa` 并使用自己的签名工具侧载。使用相同应用标识与签名团队时通常可覆盖安装并保留本地数据；签名方式改变时可能无法覆盖。安装前建议备份应用数据。真机效果仍需自行验收。

本次仅提供 iOS / iPadOS IPA；其他平台请使用上游发布渠道。
